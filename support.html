Support

Need help with CSV Bulk Importer? Here are some common troubleshooting steps.

How do I start an import?

Open a Google Sheet, open the Extensions menu, select CSV Bulk Importer, and open the bulk importer. Choose your destination tab, select or drag and drop your CSV files, and start the import.

My CSV isn't importing

Make sure the file is a valid CSV file and that you have selected a destination sheet. If you are importing several files, check that they use compatible column structures.

Where does my data go?

Imported data is appended to the destination tab that you select in the importer. Existing spreadsheet data is not intentionally overwritten by the normal append operation.
