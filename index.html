CSV Bulk Importer CSV Bulk Importer is a Google Sheets add-on designed to make importing multiple CSV files quick and easy. Features Import multiple CSV files at once Drag and drop CSV files Choose the destination Google Sheets tab Append CSV files together automatically Keep the header from the first CSV file Developer CSV Bulk Importer is independently developed as a utility for Google Sheets.
